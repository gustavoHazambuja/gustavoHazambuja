### 📌 Projetos em destaque
🔹 [Sistema de Venda de Ingressos](https://github.com/gustavohazambuja/sistema_venda_ingressos) — API backend para gerenciamento de eventos e ingressos, com controle de disponibilidade de estoque, múltiplos tipos de ingresso por evento e regras de inscrição/cancelamento.  
🔹 [Sistema de Alerta de Vagas](https://github.com/gustavohazambuja/sistema_alerta_vagas) — API para gerenciamento de alertas de vagas de emprego, com regra de matching automático entre vagas cadastradas e critérios de busca dos usuários.
